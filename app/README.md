# Private Gallery App

Flutter client for the desktop-first Private Gallery MVP.

## What It Does

- Connects to the local Rust daemon on `http://127.0.0.1:4821`.
- Starts the daemon automatically on desktop when possible.
- Shows first-run setup when no library has been initialized yet.
- Supports one-off imports from folders and removable drives.
- Renders live timeline, people, places, events, search, jobs, and settings screens.

## Run

```bash
flutter run -d linux
```

Any desktop target generated by Flutter can be used once the corresponding platform toolchain is installed.

For Android daily-driver testing, start the daemon with remote mobile mode and
invite phones from the desktop Vaults screen:

```bash
PRIVATE_GALLERY_ALLOW_REMOTE_MOBILE=1 ../scripts/private_gallery_mobile_lan_daemon.sh
```

Create a device group if needed, choose "Add Device", confirm
`http://<laptop-hotspot-ip>:4821`, and scan the generated QR from the Android
"Join group" flow. If the hotspot IP changes, create a fresh invite QR with the
current URL.

For the repeatable two-phone device lab, use the root API and app smoke scripts:

```bash
PRIVATE_GALLERY_SMOKE_DEVICE_BASE_URL=http://<laptop-hotspot-ip>:4821 \
PRIVATE_GALLERY_SMOKE_REQUIRE_DEVICE_COUNT=2 \
../scripts/android_mobile_smoke.sh

PRIVATE_GALLERY_SMOKE_DEVICE_BASE_URL=http://<laptop-hotspot-ip>:4821 \
PRIVATE_GALLERY_SMOKE_DEVICE_SERIALS="serial1 serial2" \
../scripts/android_mobile_app_smoke.sh
```

The app smoke defaults to direct debug session loading so the installed apps are
actually left paired to the same local group. Use
`PRIVATE_GALLERY_APP_SMOKE_PAIR_MODE=ui` to test the visible QR/manual pairing
flow instead.

The full runbook is in `../docs/android-mobile-smoke.md`.

Phone-created groups are metadata-only and require a build configured with
`PRIVATE_GALLERY_SUPABASE_URL` and `PRIVATE_GALLERY_SUPABASE_ANON_KEY`. Apply
`../supabase/device_group_bootstrap.sql` to the Supabase project before using
that optional path. The desktop "Join Group" action accepts pasted cloud or
hybrid invite JSON; desktop camera QR scanning is not part of this milestone.

## Validate

```bash
flutter analyze
flutter test
```

## Current MVP Limits

- Path entry is manual; native file pickers are not wired yet.
- People/search screens preserve the future API shape but are still limited until local ML and richer indexing land.
- The daemon is the source of truth; the Flutter app does not maintain an offline shadow cache in this slice.
